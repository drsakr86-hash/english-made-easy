# التشغيل والنشر والاستعادة

## تشغيل محلي (Termux أو كمبيوتر)
```
npm install
npm run dev            # تطوير
npm run build && npm run preview   # نسخة الإنتاج (تفعّل Service Worker)
npm test               # اختبارات الوحدة
npm run lint
node scripts/security-scan.mjs src dist
```
اختبار المتصفح الكامل (يحتاج playwright عالمياً وChrome): شغّل `ALLOWED_ORIGIN=http://127.0.0.1:4173 node server/index.mjs` ثم `npx vite preview --port 4173 --host 127.0.0.1` ثم `node tests/e2e/browser-smoke.mjs`.

## نشر الواجهة
الواجهة ملفات ثابتة: ارفع محتوى `dist/` (بعد `npm run build`) إلى أي استضافة ثابتة تدعم HTTPS (GitHub Pages، Netlify، Cloudflare Pages…). Service Worker يتطلب HTTPS (أو localhost). مسار التطبيق يجب أن يكون الجذر `/` (لو نُشر في مجلد فرعي عدّل `base` في vite.config.js).
المحتوى والتقدم يعملان دون خادم. المدرس الذكي فقط يحتاج الخادم الوسيط.

## نشر الخادم الوسيط للمدرس (اختياري)
```
AI_PROVIDER=anthropic ANTHROPIC_API_KEY=... ALLOWED_ORIGIN=https://موقعك AI_MODEL=claude-haiku-5-5 \
RATE_PER_MINUTE=20 DAILY_CAP=1000 PORT=8787 node server/index.mjs
```
- المفتاح في متغيرات بيئة الخادم فقط. لا يوجد أي مفتاح في الواجهة (يفحصه `scripts/security-scan.mjs`).
- `ALLOWED_ORIGIN` عنوان واجهتك بالضبط (https://…). بدونه يرفض الخادم الطلبات من أي موقع آخر.
- `DAILY_CAP` سقف يومي عام للطلبات لضبط التكلفة. ضع قيمة تناسب ميزانيتك.
- ضع الخادم خلف HTTPS (بروكسي عكسي أو منصة استضافة تعطي TLS). حد المعدل في الذاكرة: لتشغيل أكثر من نسخة استخدم حداً على مستوى البوابة.
- في التطبيق: تبويب "المدرس" ← أدخل عنوان الخادم ← "اختبار الاتصال". أو عند البناء: `VITE_AI_ENDPOINT=https://...`.
- للتجربة دون مفتاح: `AI_PROVIDER=mock node server/index.mjs` (ردود حتمية للاختبار فقط).
- لتبديل المزود: أنشئ ملفاً في `server/providers/` يعيد `{ name, complete({system, messages}) }` وأضفه في `server/index.mjs`.

## النسخ الاحتياطي والاستعادة
- من أسفل التطبيق: "تصدير نسخة احتياطية" يحفظ ملف JSON فيه كل مفاتيح التطبيق (V1 وV2: التقدم، المراجعة، الخطط، المهارات، كتاباتك، كلمات المستخدم، محادثات المدرس، الإعدادات).
- "استعادة من ملف" تتحقق من الملف كاملاً (الصيغة والإصدار والمفاتيح والأحجام وسلامة JSON الداخلي) ولا تكتب شيئاً إن كان غير صالح، ثم تعرض خيارين:
  - **دمج:** يضيف المفاتيح الغائبة، ويوحّد التقدم دون حذف عنصر، ويُبقي بياناتك الحالية الأخرى كما هي.
  - **استعادة كاملة:** تجعل بيانات التطبيق مطابقة للملف وتحذف مفاتيح التطبيق الغائبة عنه، ولا تحذف أبداً بيانات V1 ولا نسخها الاحتياطية.
  تُحفظ قبل التنفيذ لقطة بما سيتغير (`eme.backup.prerestore`)، وتُنفَّذ الكتابة كوحدة واحدة: عند فشل أي كتابة أو أي تحقق بعدها تُعاد بياناتك كما كانت. لا تظهر رسالة نجاح إلا بعد قراءة القيم المكتوبة ومطابقتها.
- عند أول تشغيل بعد V1 يُنشأ نسخ احتياطي تلقائي لبيانات V1 (`eme.backup.v1`) ويمكن الاستعادة منه من نفس الشريط. مفاتيح V1 لا تُمسّ ولا تُحذف. إن وُجد تقدم محفوظ في النسخة الجديدة مع بيانات V1 دون علامة ترحيل، لا يستبدل الترحيل شيئاً ويعرض تنبيه تعارض، ويمكن الدمج يدوياً من «استيراد بيانات V1».
- قبل أي تحديث كبير: صدّر نسخة احتياطية.

## ملاحظات خصوصية
المحادثات تُخزَّن في متصفحك فقط، وتُرسل للخادم آخر 10 رسائل ومستواك التقديري دون أي بيانات تعريفية. الخادم لا يسجل نص المحادثات. التطبيق ينبّه المستخدم ألا يكتب بياناته الشخصية.
