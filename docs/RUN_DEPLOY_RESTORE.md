# التشغيل والنشر والاستعادة

## تشغيل محلي (Termux أو كمبيوتر)
```
npm install
npm run dev            # تطوير
npm run build && npm run preview   # نسخة الإنتاج (تفعّل Service Worker)
npm test               # اختبارات الوحدة
npm run lint
node scripts/security-scan.mjs src dist
```
اختبار المتصفح الكامل (يحتاج playwright عالمياً وChrome): شغّل `ALLOWED_ORIGIN=http://127.0.0.1:4173 node server/index.mjs` ثم `npx vite preview --port 4173 --host 127.0.0.1` ثم `node tests/e2e/browser-smoke.mjs`.

## نشر الواجهة
الواجهة ملفات ثابتة: ارفع محتوى `dist/` (بعد `npm run build`) إلى أي استضافة ثابتة تدعم HTTPS (GitHub Pages، Netlify، Cloudflare Pages…). Service Worker يتطلب HTTPS (أو localhost). مسار التطبيق يجب أن يكون الجذر `/` (لو نُشر في مجلد فرعي عدّل `base` في vite.config.js).
المحتوى والتقدم يعملان دون خادم. المدرس الذكي فقط يحتاج الخادم الوسيط.

## نشر الخادم الوسيط للمدرس (اختياري)
```
AI_PROVIDER=anthropic ANTHROPIC_API_KEY=... AI_MODEL=claude-haiku-5-5 \
ALLOWED_ORIGIN=https://موقعك TUTOR_TOKEN_SECRET=<32 حرفاً عشوائياً أو أكثر> \
RATE_PER_MINUTE=20 PER_USER_DAILY=50 DAILY_CAP=300 PORT=8787 node server/index.mjs
```
**الخادم يرفض البدء (الخروج بكود 1) في الإنتاج إذا غاب `ALLOWED_ORIGIN` أو `TUTOR_TOKEN_SECRET` أو كان `ALLOWED_ORIGIN` غير https أو السر أقصر من 32 حرفاً.** الإنتاج = `NODE_ENV=production` أو أي مزود غير `mock`.

### المصادقة برموز دعوة
- كل متعلم يحمل رمزاً موقّعاً تُصدره أنت: `TUTOR_TOKEN_SECRET=... node scripts/issue-token.mjs --days 30 --label اسم`. يطبع معرّفاً (احتفظ به مع اسم صاحبه) ورمزاً يُسلَّم للمتعلم. الرمز لا يحوي أي بيانات شخصية.
- يدخل المتعلم الرمز مرة واحدة في تبويب "المدرس" (حقل "رمز الدخول") فيُحفظ في إعدادات التطبيق على جهازه ويُرسل في ترويسة `Authorization: Bearer`. لاحظ أنه يدخل أيضاً في ملف النسخة الاحتياطية مع بقية الإعدادات.
- كل الحدود تُحسب لكل رمز (مستخدم)، لا لكل عنوان IP: `RATE_PER_MINUTE` لكل مستخدم، و`PER_USER_DAILY` يومياً لكل مستخدم، و`DAILY_CAP` سقف عام للجميع. كل طلب يُنفَّذ يستهلك من الثلاثة، وحجم الطلب الواحد محدود (16KB وحدود الرسائل و`max_tokens`)، فسقف التكلفة اليومي = `DAILY_CAP` × كلفة طلب أقصى واحد.
- **الإبطال:** أضف معرّف المستخدم إلى `REVOKED_TOKEN_IDS` (مفصولة بفواصل)، أو إلى ملف يشير إليه `TUTOR_REVOKED_FILE` (سطر لكل معرّف، يُعاد قراءته كل 30 ثانية دون إعادة تشغيل). الرمز له أيضاً تاريخ انتهاء (`--days`، من 1 إلى 365).
- **تدوير السر:** ضع السر الجديد في `TUTOR_TOKEN_SECRET` والقديم في `TUTOR_TOKEN_SECRET_PREVIOUS` فتبقى الرموز القديمة صالحة حتى تنتهي أو تُبطلها، ثم احذف السابق.
- `ALLOWED_ORIGIN` عنوان واجهتك بالضبط (origin بلا مسار). أي طلب يحمل `Origin` مختلفاً يُرفض، وإن لم يُضبط يُرفض كل طلب من متصفح. **هذا تحكم متصفحات فقط وليس حماية من curl أو السكربتات؛ الحماية هي الرمز والحدود.**
- الحالة اليومية للحدود تُحفظ في الملف `LIMITS_FILE` (الافتراضي `.limits-state.json`) فتصمد أمام إعادة التشغيل العادية. **قيود:** الملف لنسخة واحدة من الخادم (لا يُشارَك بين نسخ)، وقرص الاستضافة المجاني (مثل Render) مؤقت وقد يُمسح عند إعادة النشر. لو كان الملف موجوداً لكنه تالف يُغلق الخادم أمام المدرس لباقي اليوم بدل تصفير العدّاد. لتشغيل أكثر من نسخة أو لحدود دائمة تلزم خدمة مشتركة (قرار مؤجَّل).
- لا يُسجَّل في سجلات الخادم نص المحادثات ولا الرموز ولا المفاتيح؛ يُسجَّل فقط معرّف المستخدم ونوع الطلب.
- المفتاح في متغيرات بيئة الخادم فقط. لا يوجد أي مفتاح في الواجهة (يفحصه `scripts/security-scan.mjs`).
- ضع الخادم خلف HTTPS (بروكسي عكسي أو منصة تعطي TLS).
- في التطبيق: تبويب "المدرس" ← أدخل عنوان الخادم ورمز الدخول ← "اختبار الاتصال". أو عند البناء: `VITE_AI_ENDPOINT=https://...`.
- للتجربة المحلية دون مفتاح ولا مصادقة: `AI_PROVIDER=mock ALLOWED_ORIGIN=http://127.0.0.1:4173 node server/index.mjs` (يطبع تحذير "AUTH DISABLED"؛ للتجارب فقط). لتجربة المصادقة محلياً أضف `TUTOR_TOKEN_SECRET`.
- لتبديل المزود: أنشئ ملفاً في `server/providers/` يعيد `{ name, complete({system, messages, signal}) }` وأضفه في `server/index.mjs`.

## النسخ الاحتياطي والاستعادة
- من أسفل التطبيق: "تصدير نسخة احتياطية" يحفظ ملف JSON فيه كل مفاتيح التطبيق (V1 وV2: التقدم، المراجعة، الخطط، المهارات، كتاباتك، كلمات المستخدم، محادثات المدرس، الإعدادات).
- "استعادة من ملف" تتحقق من الملف كاملاً (الصيغة والإصدار والمفاتيح والأحجام وسلامة JSON الداخلي) ولا تكتب شيئاً إن كان غير صالح، ثم تعرض خيارين:
  - **دمج:** يضيف المفاتيح الغائبة، ويوحّد التقدم دون حذف عنصر، ويُبقي بياناتك الحالية الأخرى كما هي.
  - **استعادة كاملة:** تجعل بيانات التطبيق مطابقة للملف وتحذف مفاتيح التطبيق الغائبة عنه، ولا تحذف أبداً بيانات V1 ولا نسخها الاحتياطية.
  تُحفظ قبل التنفيذ لقطة بما سيتغير (`eme.backup.prerestore`)، وتُنفَّذ الكتابة كوحدة واحدة: عند فشل أي كتابة أو أي تحقق بعدها تُعاد بياناتك كما كانت. لا تظهر رسالة نجاح إلا بعد قراءة القيم المكتوبة ومطابقتها.
- عند أول تشغيل بعد V1 يُنشأ نسخ احتياطي تلقائي لبيانات V1 (`eme.backup.v1`) ويمكن الاستعادة منه من نفس الشريط. مفاتيح V1 لا تُمسّ ولا تُحذف. إن وُجد تقدم محفوظ في النسخة الجديدة مع بيانات V1 دون علامة ترحيل، لا يستبدل الترحيل شيئاً ويعرض تنبيه تعارض، ويمكن الدمج يدوياً من «استيراد بيانات V1».
- قبل أي تحديث كبير: صدّر نسخة احتياطية.

## ملاحظات خصوصية
المحادثات تُخزَّن في متصفحك فقط، وتُرسل للخادم آخر 10 رسائل ومستواك التقديري دون أي بيانات تعريفية. الخادم لا يسجل نص المحادثات. التطبيق ينبّه المستخدم ألا يكتب بياناته الشخصية.
